# Weather Prediction App 🌦️

## About the Project

The **Weather Prediction App** is a web application that displays current weather conditions, hourly forecasts, and a 7-day weather forecast for a selected location. It uses the Visual Crossing Weather API to fetch weather data and presents it through a simple, user-friendly interface.

The application provides important weather details such as temperature, weather conditions, precipitation, humidity, wind speed, UV index, visibility, sunrise, and sunset. Users can search for different cities and switch between Celsius and Fahrenheit.

## Features

* **Current Weather:** Displays the current temperature, weather conditions, and location.
* **Hourly Forecast:** Shows hourly temperature forecasts with weather icons.
* **7-Day Forecast:** Displays weather conditions and temperatures for the upcoming days.
* **City Search:** Search for a city to view its weather information.
* **Temperature Conversion:** Switch between Celsius (°C) and Fahrenheit (°F).
* **Weather Highlights:** Displays humidity, wind speed, UV index, visibility, precipitation, sunrise, and sunset.
* **Dynamic Backgrounds:** Background images and weather icons change according to weather conditions.
* **Responsive Design:** Uses CSS media queries to adapt the layout to desktop, tablet, and mobile screens.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser, or run it using the Live Server extension in Visual Studio Code.
4. Search for a city to view its weather information.

**Note:** A valid Visual Crossing API key is required to retrieve weather data. Configure your own API key in the JavaScript file before running the application.
